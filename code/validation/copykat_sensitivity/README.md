# CopyKAT sensitivity analysis

This directory contains validation utilities for the later CopyKAT 1.2.5
known-normal rerun.

These files are intentionally outside `code/01_main_analysis/` so that the
main numerical notebook sequence reproduces the paper-defining canonical
CopyKAT result.

The sensitivity rerun is retained for transparency and robustness analysis;
it is not used automatically by downstream CNV consensus notebooks.
