# Glioma CNV-informed single-cell analysis pipeline

This package contains the cleaned, repository-ready notebooks for the full
analysis described in the manuscript, together with the four dataset-specific
preprocessing workflows.

## Execution overview

1. Run the three preprocessing notebooks for each dataset under
   `code/00_preprocessing/`.
2. Place the resulting post-QC objects under `data/processed/DS*/`.
3. Place GENCODE v49 at
   `data/reference/gencode.v49.primary_assembly.annotation.gtf.gz`.
4. Run `code/01_main_analysis/01_...` through `31_...` in numerical order.

The notebooks are intended to be run from a fresh kernel, top to bottom. They
resolve the repository root automatically or through `GLIOMA_PROJECT_ROOT`.

## Important stage boundaries

- Notebook 13 prepares CopyKAT inputs and generates R scripts. Execute the
  generated CopyKAT runner before notebook 14.
- Notebook 19 is the corrected binomial-GLM sensitivity analysis and follows
  the main differential-abundance notebook.
- Notebook 24 performs g:Profiler validation only. Enrichr has been removed.
- Notebook 27 standardizes the global LIANA labels generated by notebook 26.
- Notebook 31 is exploratory and does not constitute RNA-velocity or lineage-
  tracing evidence.

## Main expected dimensions

- Integrated object: 351,427 cells × 15,176 genes
- HVG/scVI branch: 351,427 cells × 8,000 genes
- Malignant-state analysis cells: 161,884
- CellRank subset: 20,000 cells

## Validation performed

All code cells were compiled for Python syntax after transformation. Machine-
specific `/mnt/DATA/...` paths were removed, notebook outputs were cleared,
and the broken Enrichr-dependent online-enrichment notebook was replaced with
a self-contained g:Profiler-only workflow.

Full runtime validation still requires the original GEO-derived data, GENCODE
reference, CopyKAT R environment, and the package versions listed in
`environment/requirements.txt`.
