# Archived patient-level sensitivity results

This directory contains the checked result package for the prepared v1.1.0 release. The ZIP is byte-for-byte identical to the revised manuscript's **Additional file 3**. Its 39 source files were compared with the completed local analysis outputs; no statistical inference was rerun during packaging.

- `Additional_file_3_Patient_level_sensitivity_results.zip`: three authoritative analysis stages, including design audits, composition/program tests, patient pseudobulk matrices and complete gene-level results.
- `FILE_MANIFEST.tsv`: paths inside the ZIP, sizes and SHA256 hashes of the 39 source files.
- `SHA256SUMS.txt`: SHA256 of the complete ZIP, including its README and internal manifest.
- `INPUT_CODE_MANIFEST.tsv`: hashes of 13 tracked upstream inputs and the four analysis notebooks at packaging time. Text hashes normalize CRLF to LF for cross-platform Git checkouts; compressed inputs use exact bytes. The corrected design is generated by notebook 02 and is also preserved inside the result archive.

From the repository root, verify the package and its recorded inputs without running analyses:

```bash
python scripts/verify_patient_sensitivity_release.py
```

To inspect tables, open the ZIP or extract a copy into a separate review directory. Do not overwrite working analysis outputs merely to inspect the archive. Original stage manifests and run-info files retain historical local paths; use the root `FILE_MANIFEST.tsv` to locate files inside this package.

See [the reproduction guide](../../docs/PATIENT_LEVEL_REPRODUCIBILITY.md) for execution order and interpretation. Notebook 01 is an earlier diagnostic; its outputs are not substituted for the final results of notebooks 02–04. In particular, numeric DS3 identifier collisions do not establish paired newly diagnosed/recurrent patients.

The v1.0.1 DOI, `10.5281/zenodo.23015399`, predates this sensitivity stage. The prepared v1.1.0 release has not yet received a version-specific DOI. Publishing a GitHub release is a separate action.
